### 🚀 Ключевой опыт

- Сопровождение и развитие конфигураций: **УХ**, **БП**, **БСХП**, **ДО**
- Разработки и развития расширений: от крупных до сравнительно небольших решений, а также перевод конфигураций поставки в расширения для повышения гибкости сопровождения
- Перенос функциональности из конфигураций поставки в расширения для упрощения сопровождения и обновлений
- Внедрение инструментов разработки **EDT + 1С:Напарник** и **VS Code + BSL LS**
- Обучение команды и помощь во внедрении процессов разработки
- Настройка процессов статического анализа качества и безопасности кода на базе **SonarQube**
- Подготовка процессов автоматического тестирования для команды рег. учета с использованием агентов **TeamCity**. Автоматизация сценарного тестирования решений с помощью **Vanessa Automation**
- Разработка интеграций с внешними сервисами, связанных преимущественно с обработкой и обменом большим количеством платежных документов. Внедрение интеграционных процессов на базе **Datareon ESB**
- Оптимизация запросов, транзакций и механизмов блокировок при массовой загрузке и обработке документов.
  - Ключевые проекты:
    - Устранение взаимоблокировок при подписании документов ЭДО (проблема типа «разный порядок захвата ресурсов»), анализ сценариев конкурентного доступа и переработка логики работы с блокировками.
    - Оптимизация типовой загрузки **Клиент-Банк** для такси-агрегатора: сокращение времени загрузки и обработки ~20 000 платежных документов с **8 часов до 20 минут**
- Исследую практическое применение **AI-инструментов** (в основном Cursor) в процессах разработки и сопровождения решений **1С**
- Развитие подходов **CI/CD** для 1С-проектов *(полный контур пока находится в процессе формирования)*
